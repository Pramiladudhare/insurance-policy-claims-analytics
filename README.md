# Insurance Policy & Claims Analytics

## 📊 Project Overview

This project analyzes insurance policy, customer, premium, coverage, claims, and payment data to identify key business patterns and develop interactive analytical dashboards.

The project demonstrates an end-to-end data analytics workflow using **Excel, SQL, Power BI, and Tableau**.

## 🎯 Business Objective

The objective is to transform raw insurance data into meaningful KPIs, interactive dashboards, and business insights that can support analysis of policy performance, customer segments, premiums, coverage, and claims.

## 🛠️ Tools & Technologies

* **Excel** – Data preparation, Pivot Tables, KPI calculations, and dashboard development
* **SQL** – Data analysis and business-question-driven queries
* **Power BI** – Interactive dashboard and KPI visualization
* **Tableau** – Interactive visual analytics and dashboard development

## 📌 Key KPIs

* Total Customers
* Total Policies
* Total Claim Amount
* Average Coverage Amount
* Average Premium
* Policy Status Distribution
* Customer Demographics
* Age Group Distribution
* Gender Distribution

## ❓ Key Business Questions

1. How many customers and policies are present?
2. What is the total claim amount?
3. What is the average coverage amount?
4. What is the average premium?
5. How are policies distributed across age groups?
6. How are policies distributed by gender?
7. How are policies distributed by status?
8. Which policy categories contribute most to the business?
9. What patterns can be observed in claims and premiums?
10. Which customer segments require further analysis?

The complete project contains **21 business questions analyzed using SQL and dashboard-based analysis**.

## 🔄 Analytics Workflow

Raw Data → Data Cleaning → SQL Analysis → KPI Development → Excel Analysis → Power BI → Tableau → Business Insights
